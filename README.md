# K.seq 建築構造積算（躯体専門）Webサイト

個人で建築構造積算業務（躯体工事の数量拾い出し）を受託するための
Webサイトです。フレームワークは使わず、素のHTML / CSS / JavaScript で
作っています。文章や画像を後から差し替えやすい構造にしています。

---

## ファイル構成

```
new-company-site/
├── index.html        … HOME（トップページ）
├── services.html     … 事業内容
├── flow.html         … ご依頼の流れ
├── contact.html      … お問い合わせ（フォームの見た目のみ）
├── css/
│   └── style.css     … サイト全体のデザイン（色・文字・余白をここで管理）
├── js/
│   └── main.js       … スマホ用ハンバーガーメニューの開閉
├── assets/
│   └── img/          … 画像置き場（使い方は img/README.md 参照）
└── README.md         … このファイル
```

---

## 表示・確認方法

特別なソフトは不要です。次のどちらかで確認できます。

1. **かんたんな方法**
   `index.html` をダブルクリックして、ブラウザで開く。

2. **おすすめの方法（ローカルサーバー）**
   フォルダ内で以下を実行し、表示されたURL（例 `http://localhost:8000`）を
   ブラウザで開きます。ページ間のリンクも正しく動きます。

   Python がある場合：
   ```bash
   python -m http.server 8000
   ```

## よくある編集ポイント

- **サイト名を変える**：各HTMLの `K.seq`（ロゴ・フッター・著作権表示
  `© 2026 K.seq`）を書き換え。
- **色・フォントを変える**：`css/style.css` の先頭 `:root { ... }` を編集。
  ここを変えるだけでサイト全体の見た目が変わります。
- **文章を変える**：各HTMLの本文テキストを直接書き換え。
- **画像を入れる**：`assets/img/` に画像を置き、`<img>` で読み込み。
